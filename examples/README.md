# Example packages

Three real packages from the week of 2026-10-13, as the pipeline produced them. Videos are included **without
sound** (the soundtrack is a licensed library track that cannot be redistributed).

| Package | Slot | Format |
|---|---|---|
| [pr-20261013-2](pr-20261013-2/) | 13:00 · Who played that? | Single post + clip: the players behind Bill Withers's "Use Me" |
| [pr-20261013-3](pr-20261013-3/) | 18:00 · The story | Thread + card: Orchestre Poly-Rythmo de Cotonou |
| [pr-20261016-1](pr-20261016-1/) | 08:00 · On this day | Single post + card: Art Blakey's The African Beat |

Each folder holds:
- `brief.json` — slot, role, genre, pillar, subject and the visual spec the renderer reads;
- `sources.md` — every fact with its URL and retrieval date;
- `post.md` — the published text (thread posts separated by `---`);
- `qa.md` — the independent QA report;
- `alt.txt`, `link.txt`, `status.json` — alt text, official listening link, publication record;
- `card.png` / `contact-sheet*.png` / `clip-vertical-muted.mp4` — rendered media.
